# FalloutDay — Editorial Review Cadence

## Weekly (15–30 minutes)

- Review one version-sensitive page before changing any claim that says or implies “current”, “best”, or “meta”.
- Use an official Fallout 76 source for official updates; distinguish source facts from editorial opinion.
- Update the visible `Last reviewed` date only after a real content review.
- Check the recent Vercel deployment, browser console, key deep links, and the single advertising trial placement.

## Monthly

- Review the Builds and Guides hub pages and add links to the most useful new content.
- Update sitemap for any new public URL.
- Compare Search Console impressions/clicks with Plausible entry pages.
- Identify one query or reader problem worth addressing with a new guide or a substantive improvement to an existing guide.

## Editorial integrity rules

- Do not copy Wiki/competitor text, tables, build descriptions, game files, or data dumps.
- Do not call a recommendation “official”, “best”, or “current” without appropriate evidence and a review date.
- Keep the non-affiliation statement visible.
- Keep commentary, official facts, and test observations clearly separate.
