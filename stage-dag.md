# falloutday — Stage DAG

```text
00 setup & scope
  → 01 keyword/market research
    → 02 PRD + route contract
      → 03 advertising/pricing posture ─┐
      → 04 compliance/IP review ────────┤
        → 05 SEO copy freeze             │
          → 06 design                    │
            → 07 content/data contract   │
              → 08 implementation ───────┘
                → SEO + compliance + PM rechecks
                  → independent QA
                    → owner review
                      → launch
                        → data review
```

## Hard gates
- No branded/franchise-derived content or trademark-like domain positioning until IP/editorial scope is reviewed.
- No ad scripts until original content, public contact route, Privacy/Terms/editorial disclosures, and production QA are verified.
- No production DNS/hosting change without explicit owner approval.
